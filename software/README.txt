Oracle 21c Software Directory
=============================

Place the following Oracle software in this directory:

REQUIRED:
---------
LINUX.X64_213000_db_home.zip

Download from:
https://www.oracle.com/database/technologies/oracle21c-linux-downloads.html

File size: Approximately 3.0 GB

IMPORTANT:
----------
You must have an Oracle account to download this software.
Accept the Oracle Technology Network License Agreement.

After downloading, verify the file is in this directory before running:
vagrant up primary
